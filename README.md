# 나만의 투두 (PWA)

매일 쓰는 나만의 투두 — 아이폰 사파리에서 열고 '홈 화면에 추가'하면 앱처럼 쓸 수 있는 웹앱(PWA)입니다.

- 주소: https://naomi658.github.io/my-todo/
- 달력에서 날짜별로 루틴·할 일·운동을 체크·추가·수정·삭제
- **루틴 관리** 화면: 루틴 이름·분류·시간·반복 주기를 등록하고 수정·켜기/끄기·삭제
  - **매주(요일)**: 매일/평일/주말 빠른 선택으로 요일 조합 지정
  - **매월(특정 일자)**: `매월 20일`처럼 일자(1~31)를 지정해 매월 반복.
    `주말이면 그 주 금요일로`를 켜면 토요일은 하루 전, 일요일은 이틀 전 금요일에 들어감
    (예: 2026-12-20 일요일 → 2026-12-18 금요일). 그 달에 없는 날(2월 31일)은 그 달 말일로 보정
  - 등록한 루틴이 그 날에 맞춰 `+ 오늘 루틴`·자동 채우기로 들어감
- JSON 내보내기 / 불러오기로 기기 백업·이전 (루틴 설정도 함께)
- 오프라인에서도 앱 셸이 열리도록 Service Worker 캐시 사용

## 기록은 어디에 저장되나요

앱에는 **개인 기록이 전혀 들어 있지 않습니다.** 방문자가 입력하거나 불러온 기록은 그 브라우저의
`localStorage`에만 저장되고, 서버로 전송되거나 저장소에 올라가지 않습니다.

투두메이트에서 내려받은 기록 파일(`todomate-records.json`, `{records:[{date, items:[…]}]}` 형식)을
**JSON 불러오기**로 한 번 불러오면 이 기기에 그대로 들어옵니다. 기존 백업 파일
(`{v, items:{…}, routines:[…]}` 형식)과 날짜별 배열 맵(`{"YYYY-MM-DD":[["제목","T",1,""]]}`)도 함께 지원하며,
여러 번 불러와도 같은 항목은 중복되지 않습니다.

기록 파일에 루틴 설정이 없으면 지금 루틴은 그대로 두고, 내보낸 백업 파일에는 루틴이 함께 담겨
불러올 때 같이 복원됩니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 화면 (PWA 메타 태그 포함) |
| `app.js` | 앱 로직 (달력, 하루 보기, 루틴 관리, 저장, JSON 내보내기/불러오기) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | Service Worker (오프라인 앱 셸 캐시) |
| `icon-192.png`, `icon-512.png`, `icon-180.png` | 앱 아이콘 |
